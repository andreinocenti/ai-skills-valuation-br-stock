# Formulas

## Por Acao

- `LPA = lucro_liquido / acoes`
- `VPA = patrimonio_liquido / acoes`
- `DPA = dividendos / acoes`
- `FCF_por_acao = fluxo_caixa_livre / acoes`

## Preco e Multiplo

- `P_L = preco_atual / LPA`
- `P_VP = preco_atual / VPA`
- `Dividend_Yield = DPA / preco_atual`
- `P_FCF = preco_atual / FCF_por_acao`
- `EV_EBITDA = enterprise_value / EBITDA`

## Rentabilidade e Divida

- `ROE = lucro_liquido / patrimonio_liquido`
- `ROIC = NOPAT / capital_investido`
- `margem_liquida = lucro_liquido / receita`
- `margem_EBITDA = EBITDA / receita`
- `divida_liquida = divida_bruta - caixa`
- `divida_liquida_EBITDA = divida_liquida / EBITDA`
- `cobertura_juros = EBIT / despesa_financeira`

## Valuation

- `Graham = sqrt(22.5 * LPA * VPA)`
- `Preco_Teto_Bazin = dividendo_medio_recorrente / yield_desejado`
- `DDM = dividendo_esperado / (Ke - g)`
- `FCFE = lucro_liquido + D_A - CAPEX - delta_capital_giro + captacao_liquida_divida`
- `FCFF = EBIT * (1 - IR) + D_A - CAPEX - delta_capital_giro`
- `Valor_Equity_FCFE = soma(FCFE_descontado) + valor_terminal_descontado`
- `Valor_Firma_FCFF = soma(FCFF_descontado) + valor_terminal_descontado`
- `Valor_Equity = valor_firma - divida_liquida`
- `Preco_Justo = valor_equity / acoes`
- `Margem_Seguranca = (valor_justo - preco_atual) / valor_justo`
- `Yield_on_Cost = dividendo_futuro_por_acao / preco_pago_hoje`
- `Lucro_Residual = lucro_liquido - (Ke * patrimonio_liquido)`

## Lynch

- `Indice_Lynch = (crescimento_projetado_LPA + dividend_yield_recorrente) / P_L`

Faixas:

- `< 1.0`: cara
- `1.0 a 1.5`: justa
- `1.5 a 2.0`: barata
- `> 2.0`: barganha
